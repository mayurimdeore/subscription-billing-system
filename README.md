# Subscription Billing System

## Overview

Subscription Billing System is a backend-focused application designed to manage customer subscriptions, subscription plans, billing cycles and invoice generation.

The project is being developed using Java, Spring Boot, REST APIs and MySQL.

## Features

- Customer management
- Subscription plan management
- Subscription creation and tracking
- Billing cycle management
- Invoice generation
- REST APIs
- Database integration
- Exception handling
- Input validation
- Role-based access

## Technology Stack

- Java
- Spring Boot
- Spring Data JPA
- Hibernate
- REST API
- MySQL
- Maven
- Git
- GitHub
- Postman

## Project Structure

The application follows a layered architecture:

- Controller
- Service
- Repository
- Entity
- DTO
- Exception Handling

## Database

MySQL will be used as the relational database.

Planned entities include:

- Customer
- Subscription
- SubscriptionPlan
- Invoice
- Payment

API endpoints will be added as the backend modules are developed.
